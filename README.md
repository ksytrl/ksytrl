# 清风阅读 · 本地小说阅读器

一个纯前端（无后端、无第三方依赖、不上传任何数据）的网页版小说阅读器：

- **PDF / EPUB / TXT 分栏导入**，每栏只认自己的类型；另有 MOBI、AZW3、DOCX、HTML、Markdown、FB2、RTF
- 可以**一键把整个文件夹的书入库**（按子目录自动分类）
- 自动识别编码，**清除乱码与推广网址**，**智能排版**
- **多种章节划分格式**，并能**把换了写法、被并进上一章的漏章补回来**
- **上下无缝滚动阅读**（也可切换成一章一页），随时**跳转任意章节**
- 导入时**书名里的网址、站点名会被自动清掉**
- **书架封面**、**书架分组与搜索**、**书签与笔记**（可导出）、**朗读听书**、**整库备份与恢复**、**可安装成 App 并离线使用**

每版改了什么见 [CHANGELOG.md](CHANGELOG.md)；
上线文件（双击即用的单文件版）：[`dist/novel-reader.html`](dist/novel-reader.html)。

## 快速开始

方式一：本地起一个静态服务器（推荐，浏览器要求 ES module 走 http 协议）

```bash
npm start          # 或 python3 -m http.server 8080
# 打开 http://localhost:8080
```

方式二：单文件版，双击即可离线使用

```bash
npm run build      # 生成 dist/novel-reader.html
```

`dist/novel-reader.html` 把 HTML / CSS / JS 全部内联，直接双击用浏览器打开就能用。

仓库 `samples/` 里有可直接试的样例：带广告乱码的 TXT（UTF-8 / GBK 各一份）、
章节写法不统一的 TXT、一本 EPUB、一份中文 PDF。

## 功能

### 1. 文本清洗（乱码 / 广告 / 网址）

| 能力 | 说明 |
| --- | --- |
| 编码识别 | UTF-8、GBK/GB18030、BIG5、UTF-16 LE/BE，带 BOM 与无 BOM 都能识别；识别不准可在导入弹窗手动切换，实时重新预览 |
| 删除网址 | `http(s)://…`、`www.xxx.com`、裸域名 `shubaow.cc/12/`、全角 `ｗｗｗ．ｘｘ．ｃｏｍ`、混淆写法 `xxx点com`、`w w w . x x . c o m`，以及邮箱 |
| 删除广告 | 内置 73 条常见站点水印 / 推广关键词（"最新章节请访问""一秒记住""本书由 XX 手打""请支持正版"……），另可自定义追加关键词 |
| 删除乱码 | 整行乱码判定（可读字符占比过低）、`锟斤拷`、`烫烫烫`、`锘匡` 等典型错码；对"UTF-8 被当成 Latin-1 读"的乱码会尝试**还原**成正确文字，而不是直接删掉 |
| 删除分隔线 | `====`、`----`、`※※※` 等无意义整行符号 |
| 清洗书名 | `盘龙(www.biquge.com)【完结】.txt` → `盘龙`；`【笔趣阁 www.xx.cc】斗破苍穹` → `斗破苍穹`；EPUB / PDF 则优先用文件里的书名元信息再清洗 |

### 2. 自动排版

- 合并被硬换行截断的句子，还原成自然段（按全文行宽自适应，不会把对话行粘起来）
- 压缩连续空行（保留几行可调）、统一段首缩进、去行尾空白、可选半角标点转全角
- 导入前**实时预览**：左边是识别出的章节，右边是排版后的正文，顶部显示删了多少网址 / 广告行 / 乱码行、合并了多少断行

### 3. 多格式章节划分 + 补回漏掉的章

内置规则可任意勾选组合，每条规则显示在本书中的**命中次数**：

| 规则 | 例子 |
| --- | --- |
| 第N卷 / 第N部 / 第N篇 | `第一卷 少年游` |
| 第N章 / 节 / 回 / 话 / 集 / 幕 | `第十二章 归途`、`第3节 雨夜` |
| 特殊章 | `楔子`、`序章`、`引子`、`番外 后日谈`、`后记`、`大结局` |
| 编号标题 | `一、开端`、`1. 开端` |
| 纯数字成行 | `001` |
| 括号编号 | `（一）开端`、`【第3章】`、`[1] 开端` |
| 英文 | `Chapter 1 Dawn`、`Part II`、`Episode 3` |
| 符号标题 | `★ 开端 ★`、`※ 卷首 ※` |
| 自定义正则 | 例如 `^※.+※$` |

**补章（章节号连号校验）** —— 解决"整本 130 章里，第 123、689 章因为换了写法没被识别，
结果那几章全被并进了上一章"这种情况：

1. 从已识别的标题里解析章节号（支持 `第一百二十三章`、`第123章`、`Chapter 123`）
2. 找出号码缺口（比如识别到 122 → 124，中间缺 123）
3. 回到上一章的正文里，用宽松规则找 `123`、`(123)`、`【123】`、`123、标题`、`第123節`、`123 标题` 等写法
4. 找到就在那一行切开、补成独立章节；找不到就如实报告"仍缺第 X 章"

排版阶段也会保护这些"疑似标题行"，不让它们被合并进正文，否则后面就补不回来了。
默认开启，可在导入弹窗关闭。

### 4. 分栏导入：PDF / EPUB / TXT / 其他格式

书架顶部分成 **PDF、EPUB、TXT、其他格式** 四栏，**每栏只认自己的类型**：
选文件时文件框只列该类型，导入文件夹时也只扫描该类型（PDF 栏只捡 `.pdf`，EPUB 栏只捡 `.epub`，
依此类推）。拖进来的文件如果整批属于另一栏，会自动切到那一栏再导入。

解析用的是社区里最成熟的实现，直接 vendored 进仓库（见 `vendor/README.md`）：

| 格式 | 解析方式 |
| --- | --- |
| PDF | [Mozilla pdf.js](https://github.com/mozilla/pdf.js) 3.11.174（UMD 构建 + Worker），加载不到时退回自研最小解析器 |
| EPUB | [JSZip](https://github.com/Stuk/jszip) 3.10.1 解包 + 自研 OPF / nav / ncx 解析，JSZip 不可用时退回自研 ZIP 读取 |
| TXT | 自研多编码识别（UTF-8 / GBK / GB18030 / BIG5 / UTF-16） |
| MOBI / AZW / AZW3 / PRC | 自研 PalmDB + PalmDOC 解压（带 DRM 或 HUFF/CDIC 压缩会明确提示） |
| DOCX | JSZip + `word/document.xml` |
| HTML / XHTML | 标签转文本，按 `<meta charset>` 或 XML 声明选编码 |
| Markdown | 去掉标记保留正文 |
| FB2 | XML 正文提取，按 XML 声明选编码（支持 GBK） |
| RTF | 控制字剥离 + `\'xx` 字节按 `\ansicpg` 码页还原（936/950/1252） |

- **EPUB**：自己实现的最小 ZIP 读取（浏览器原生 `DecompressionStream`）+ OPF / spine 解析，
  兼容带命名空间前缀的写法（`<opf:item>`、`<ncx:navPoint>`）、EPUB2 的 `toc.ncx` 与
  EPUB3 的 `nav`、以及带 `%20`、`../` 的路径；整本只有一个 xhtml 时会自动改用规则分章。
  也可以随时选择"忽略自带目录，按规则重新识别"
- **PDF**：自己实现的最小文本提取器（对象扫描 + 对象流展开 + FlateDecode + ToUnicode CMap +
  内容流 `Tj/TJ/'/"` 解析），支持现代 PDF 常见的对象流(ObjStm)/交叉引用流结构；
  会自动去掉每页重复的页眉与页码（否则页码会被当成章节号）。
  扫描图片版可以直接用内置的 OCR 识别（见下文），加密 PDF 会提示先解除加密
- **文件夹**：点"一键导入整个文件夹"或直接把文件夹拖进来，逐本自动识别编码、清洗、分章、
  清洗书名并入库，重复的书会自动跳过，全程有进度和结果清单

以上都不依赖任何第三方库。

### 5. 书架：几百本也井然有序

书多了最怕乱，所以书架是按"大书库"来设计的：

- **左侧分类侧栏**：上半是阅读状态（全部 / 在读 / 未读 / 读完），下半是全部分类，
  每项都带数量，点一下即筛选
- **封面墙视图**（默认）：一屏能看十几二十本，点右上角图标可切回**列表视图**
  （列表里有分类、格式、笔记数量和操作按钮）
- **分页**：封面墙每页 60 本、列表每页 24 本；封面按当前页**按需加载**，
  200 本的书架打开约 2 秒
- **搜索与排序**：按书名或分类搜索；最近阅读 / 最近导入 / 书名（中文按拼音）/ 阅读进度
- **批量管理**：点「批量管理」后多选书籍，一次改分类或删除，可全选本页
- **智能整理**：一键按三种方式重新分类，应用前会告诉你会分成几类、都有哪些：
  | 方式 | 效果 |
  | --- | --- |
  | 按格式 | PDF / EPUB / TXT / MOBI … 一眼看出是什么文件 |
  | 按阅读状态 | 在读 / 未读 / 读完，接着读哪本一目了然 |
  | 按书名系列 | 「斗破苍穹 第一部」「第二部」归到同一系列，落单的进「单本」 |
- **导入文件夹时自动按子目录建分类**：`书库/玄幻/某书.txt` 会被放进「玄幻」，
  拖进来的文件夹同样按目录层级归类

### 6. 书签与笔记

- 阅读时点"书签"面板里的按钮，即可在当前位置加书签（自动记下所在章节与页内位置，并摘一句原文）
- **选中正文里的一段文字**会弹出浮层：可以"写笔记"或"存为书签"；笔记引用的原文在正文里带下划线高亮
- 书签面板按章节顺序列出全部书签与笔记，可跳转、编辑、删除，`B` 打开面板、`D` 直接加书签
- 支持一键**导出为 Markdown**（按章节组织的引用 + 笔记）
- 书签笔记存在 IndexedDB 里，跟着书走，刷新和重启浏览器都在

### 7. 书里的图片与视频

- **EPUB**：插图（`<img>`）、SVG 封面页（`<svg><image>`）、视频（`<video>` / `<source>`）、
  音频与 data: URI 图片都会保留，同一张图多处引用只存一份，`alt` 显示为图注
- **PDF**：用 pdf.js 的操作符列表跟踪变换矩阵，找出每张图在页面上的位置，
  裁出来按纵坐标插回原文；整页背景图和装饰小图会被过滤
- 阅读时原位显示；图片点一下看大图，视频 / 音频带播放控件；朗读会自动跳过
- 媒体文件存在 IndexedDB，跟着书走：删书时一并清理，完整备份里一起带上
- 限制：PDF 里的视频（RichMedia 注释）、MOBI / DOCX 里的图片暂不支持；
  整本都是扫描图的 PDF 仍然走 OCR 流程

### 8. 书架封面

- **EPUB** 取书里自带的内封（`<meta name="cover">` / `properties="cover-image"` / 文件名兜底）
- **PDF** 用 pdf.js 渲染首页当封面
- 其余格式按**书名生成**一张配色封面：色相由书名决定（同一本书每次生成都一样），
  竖排书名 + 书脊质感
- 鼠标移到封面上可以**换图**（选本地图片，自动裁成 300×420）或**重新生成**
- 封面存在 IndexedDB，跟着书走，备份 / 恢复时一并带上

### 9. 朗读听书

- 阅读时点顶栏 **「朗读」**（或按 `P`）开始朗读，底部出现播放条
- 用浏览器自带的语音合成，**逐句朗读、读到哪句高亮哪句**，画面自动跟到当前句
- 一章读完**自动接下一章**，没有正文的卷标题会自动跳过，全书读完会提示
- 播放条上可以暂停/继续、上一句/下一句、切换**语速（0.75x ~ 2x）**与**音色**，
  设置会记住；回书架自动停止
- 不联网、不上传，用的是系统里已有的语音（手机上通常需要装中文语音包）

### 10. 扫描版 PDF 的 OCR

整页是图片的 PDF（扫描 / 拍照）本来读不出文字，现在可以直接在浏览器里识别：

- 导入时如果提取不到文字，错误弹窗上会出现 **「用 OCR 识别文字」**；
  文字版 PDF 的导入窗里也有 **「这页是图？用 OCR 识别」**，混排的书同样能救
- 识别用 [tesseract.js](https://github.com/naptha/tesseract.js)：先用 pdf.js 把每页渲染成图，再逐页识别
- 可选 **简体中文 / 简体+英文 / 繁体中文 / 英文**，三档清晰度，可指定页码范围
  （`1-20`、`1,5,8-10`），页数多时建议先识别前几页试效果
- 识别过程有进度条，可随时停止；识别完先给预览，确认没问题再导入
- 识别出的中文会自动去掉字间空格，再走正常的清洗、排版、分章流程
- **全部在本机进行，文件不会上传**。简体中文语言包（1.7 MB 量化版）随仓库自带，
  离线可用；繁体 / 英文语言包按需从 CDN 下载。单文件版没有 vendor 目录，
  OCR 引擎与语言包需要联网下载（离线场景请用模块版或已安装的 PWA）

### 11. 备份与恢复

- 阅读设置面板里有 **导出备份 / 只导进度笔记 / 恢复备份**
- **完整备份**：一个 JSON，含书架、正文、章节、阅读进度、书签笔记与阅读设置，
  换设备或清了浏览器数据都能原样恢复
- **轻量备份**：不含正文（体积通常只有完整备份的几十分之一），适合"书还在、
  只想保住进度和笔记"的情况
- 恢复时按书 id 或"书名 + 字数"识别：书已经在书架上就**只合并进度与书签笔记**
  （取更新的那一份），不会产生重复条目；重复恢复同一份备份也不会重复建书

### 12. 上次读到这里

- 打开书自动回到上次的位置，顶部提示条写明"第几章、本章百分之多少"，
  正文里画一条 **「上次读到这里」** 的分隔线
- 提示条上可以一键"回到本章开头"，8 秒后自动隐去

### 13. 安装成应用（PWA）

- 带 `manifest.webmanifest` 与 Service Worker：可以"添加到主屏幕 / 安装到桌面"，独立窗口打开
- 应用外壳离线缓存，**断网也能打开继续读**（书籍本来就存在本地 IndexedDB）
- 浏览器支持时顶栏会出现"安装"按钮

### 14. 阅读体验

- **上下无缝滚动**（默认）：向下滚自动接上下一章，向上滚自动补回上一章，顶栏实时显示当前章节；
  远处的章节会被移出 DOM，长时间滚动也不卡。也可以在设置里切换成"一章一页"
- 目录面板：整本目录、当前章高亮、正序/倒序、标题过滤
- **全文搜索**：输入 2 字以上直接搜正文，列出命中章节与上下文，点击跳过去并高亮
- 章节号直达、上一章 / 下一章、`←` `→` 翻章
- 快捷键：`T` 目录、`S` 设置、`G` 跳章、`+` `-` 字号、`Esc` 关闭面板
- 四套主题（白日 / 护眼 / 暗色 / 夜间）、字号行距字距段距页宽、四种字体、自动滚动
- 阅读进度（章节 + 章内位置）自动保存，下次打开自动续读
- 可导出**排版后的干净 TXT**

## 测试

```bash
npm test     # 99 项：网址/广告/乱码清洗、排版、8 类分章、补章、书名清洗、编码、EPUB、PDF
```

浏览器端用 Playwright 跑了十一套端到端流程（共 197 项，模块版全过；单文件版跳过 PWA 与 OCR 联网相关项）：

- 回归 24 项：导入 GBK TXT → 清洗预览 → 阅读 → 翻章 → 跳章 → 目录/正文搜索 → 主题字号 → 刷新续读 → 重新排版 → 粘贴导入
- 分章与格式 24 项：补章（16 章 vs 关闭补章 12 章）→ 无缝滚动上下自动接章 → 模式切换 →
  EPUB（自带目录 / 按规则）→ PDF → 批量导入与书名清洗、重复跳过
- 图片与视频 20 项：EPUB 插图原位显示与图注、看大图、视频可加载播放、SVG 封面页、
  PDF 插图裁出并插回两段之间、导出 TXT 的替换、删书清理、完整备份带图并能恢复
- 大书库 21 项：直接塞 200 本进 IndexedDB，验证打开速度、分页、侧栏筛选、
  智能整理（按系列）、批量改分类与批量删除、两种视图
- 封面 8 项：TXT 生成封面、EPUB 内封、PDF 首页、尺寸、手动换图、重新生成、持久保存
- 朗读 19 项：朗读条、音色与语速、逐句高亮、上一句/下一句、暂停继续、
  一章读完自动接下一章（空卷标题自动跳过）、快捷键与退出（用注入的假语音引擎测，
  无头浏览器里没有系统语音）
- OCR 11 项：扫描版 PDF 给出说明与入口、语言/清晰度/页码范围、真实识别一页中文并
  进入导入流程、识别结果可正常阅读（样例 1 页约 2 秒）
- 备份与续读 14 项：完整/轻量备份导出、清空数据后恢复、进度与书签恢复、
  重复恢复不产生重复书、"上次读到这里"提示条与分隔线
- 分栏与多格式 19 项：四个分栏的过滤与文案、PDF 走 pdf.js、对象流 PDF、
  MOBI / DOCX / HTML / Markdown / FB2 / RTF 各自能读出正文、混合类型只导入本栏的
- 格式健壮性 10 项：带命名空间前缀的 EPUB、EPUB3 nav 目录、整本单文档 EPUB、
  对象流(ObjStm) PDF、坏文件的错误提示、版本号
- 书架与阅读辅助 26 项：按目录建分类 → 分类筛选/搜索/排序/改分类 → 加书签 → 选中文字写笔记 →
  笔记高亮 → 跳转 → 刷新后仍在 → 删除 → manifest / Service Worker / **断网后仍能打开并继续阅读**

## 性能

用 5.5 MB / 2000 章的 TXT 实测（Chromium，含清洗与分章）：

| 操作 | 耗时 |
| --- | --- |
| 解析 + 清洗 + 分章 + 预览 | ~1.6 s |
| 入库并打开阅读 | ~0.6 s |
| 渲染 2000 章目录 | ~0.3 s |
| 跳转到第 1500 章 | ~0.07 s |
| 全文搜索 | ~0.8 s |

无缝滚动时只保留当前章附近的十来章，连续滚动 20 屏后页面里仍只有 11 章、约 1800 个 DOM 节点。

## 隐私

书籍正文、书签与笔记存在浏览器的 IndexedDB，阅读设置存在 localStorage，**不会上传到任何服务器**；
Service Worker 只缓存应用自身的静态文件。删除书籍即从本地清除（连同它的书签笔记）。
