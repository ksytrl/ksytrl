# 清风阅读 · 本地 TXT 小说阅读器

一个纯前端（无后端、无依赖、不上传任何数据）的网页版小说阅读器：
导入 TXT 后自动识别编码、**清除乱码与推广网址**、**自动排版**，
支持**多种章节划分格式**，并且可以**随意跳转到任意章节**。

## 快速开始

方式一：本地起一个静态服务器（推荐，浏览器要求 ES module 走 http 协议）

```bash
npm start          # 或 python3 -m http.server 8080
# 打开 http://localhost:8080
```

方式二：单文件版，双击即可离线使用

```bash
npm run build      # 生成 dist/novel-reader.html
```

`dist/novel-reader.html` 已经把 HTML / CSS / JS 全部内联，
直接双击用浏览器打开就能用，也方便拷给别人或放进网盘。

仓库里的 `samples/` 有两份"脏"样例（UTF-8 与 GBK 各一份），可以直接拿来试。

## 功能

### 1. 文本清洗（解决乱码 / 广告 / 网址）

| 能力 | 说明 |
| --- | --- |
| 编码识别 | UTF-8、GBK/GB18030、BIG5、UTF-16 LE/BE，带 BOM 与无 BOM 都能识别；识别不准时可在导入弹窗手动切换，实时重新预览 |
| 删除网址 | `http(s)://…`、`www.xxx.com`、裸域名 `shubaow.cc/12/`、全角 `ｗｗｗ．ｘｘ．ｃｏｍ`、混淆写法 `xxx点com`、`w w w . x x . c o m`，以及邮箱 |
| 删除广告 | 内置 73 条常见站点水印 / 推广关键词（"最新章节请访问""一秒记住""本书由 XX 手打""请支持正版"……），另可自定义追加关键词 |
| 删除乱码 | 整行乱码判定（可读字符占比过低）、`锟斤拷`、`烫烫烫`、`锘匡` 等典型错码；对"UTF-8 被当成 Latin-1 读"的乱码会尝试**还原**成正确文字，而不是直接删掉 |
| 删除分隔线 | `====`、`----`、`※※※` 等无意义整行符号 |

### 2. 自动排版

- 合并被硬换行截断的句子，还原成自然段（按全文行宽自适应判断，不会把对话行粘起来）
- 压缩连续空行（保留几行可调）
- 统一段首缩进两个全角空格、去行尾空白、可选半角标点转全角
- 导入前有**实时预览**：左边是识别出的章节，右边是排版后的正文片段，顶部显示"删了多少网址 / 广告行 / 乱码行、合并了多少断行"

### 3. 多格式章节划分

内置规则可任意勾选组合，每条规则会显示在本书中的**命中次数**：

| 规则 | 例子 |
| --- | --- |
| 第N卷 / 第N部 / 第N篇 | `第一卷 少年游` |
| 第N章 / 节 / 回 / 话 / 集 / 幕 | `第十二章 归途`、`第3节 雨夜` |
| 特殊章 | `楔子`、`序章`、`引子`、`番外 后日谈`、`后记`、`大结局`、`作者的话` |
| 编号标题 | `一、开端`、`1. 开端` |
| 纯数字成行 | `001` |
| 括号编号 | `（一）开端`、`【第3章】`、`[1] 开端` |
| 英文 | `Chapter 1 Dawn`、`Part II`、`Episode 3` |
| 符号标题 | `★ 开端 ★`、`※ 卷首 ※` |
| 自定义正则 | 例如 `^※.+※$`，匹配整行标题 |

- **自动识别分章方式**：一键按命中情况挑选最合适的规则组合（主规则 + 分卷 + 特殊章）
- 分卷标题在目录中单独加粗显示，形成"卷 → 章"的层级
- 完全识别不到标题时，可按每 N 行自动分章，保证任何文本都能跳章
- 已导入的书随时可以点顶栏"重新排版"，换清洗选项或分章规则重来一遍，阅读进度会保留

### 4. 随意跳章与阅读体验

- 目录面板：整本目录、当前章高亮、正序/倒序、标题过滤
- **全文搜索**：输入 2 字以上直接搜正文，列出命中章节与上下文片段，点击跳过去并高亮关键词
- 章节号直达：底部 / 目录里输入第几章，回车即到
- 上一章 / 下一章按钮，`←` `→` 键翻章
- 快捷键：`T` 目录、`S` 设置、`G` 跳章、`+` `-` 字号、`Esc` 关闭面板
- 四套主题（白日 / 护眼 / 暗色 / 夜间）、字号、行距、字距、段距、页宽、四种字体、自动滚动
- 阅读进度（章节 + 页内位置）自动保存，下次打开自动续读；书架显示每本的进度百分比
- 支持导出**排版后的干净 TXT**

## 目录结构

```
index.html              页面结构
assets/style.css        主题与样式
src/encoding.js         编码识别与解码（多编码试解码 + 打分）
src/chapters.js         章节规则、自动识别、切分、按行数兜底
src/cleaner.js          网址 / 广告 / 乱码清洗与自动排版
src/store.js            IndexedDB 书架 + localStorage 阅读设置
src/app.js              界面逻辑（导入、阅读、目录、搜索、设置）
tools/build-standalone.mjs  打包成单文件 HTML
tests/run-tests.mjs     纯逻辑单元测试
samples/                带广告、网址、乱码的示例 TXT（UTF-8 / GBK）
```

## 隐私

书籍正文存在浏览器的 IndexedDB，阅读设置存在 localStorage，**不会上传到任何服务器**。
删除书籍即从本地清除。
